# TikZ Editor

[**웹에서 TikZ 도형 직접 편집하기**](https://acb0808.github.io/TikZ-Editor/)

수학 시험지에 들어갈 그림을 웹 화면에서 열어 마우스로 고치고 TikZ 파일로 저장하는 편집기입니다. 좌표나 TikZ 코드를 몰라도 도형을 선택하고 옮기거나 크기·색·라벨을 조절할 수 있습니다.

## 시험지 도형을 고치는 가장 쉬운 방법

1. 시험지 복원 결과에 들어 있는 해당 문항의 `.tikz` 또는 `.tex` 도형 파일을 받습니다.
2. 위 웹 편집기를 엽니다. **폴더 모양 버튼**을 눌러 JSON, TikZ 또는 TeX 파일을 선택합니다.
3. 캔버스에서 도형이나 점을 마우스로 선택해 이동하고, 오른쪽 속성 패널에서 이름·위치·크기·선 모양을 조정합니다.
4. 필요하면 점·선·원·다각형·텍스트·수식·함수 그래프를 추가합니다. 선을 도형의 점에 가까이 그리면 그 점에 연결되고, 원 나누기 도구로 호나 부채꼴을 만들 수 있습니다.
5. **내보내기 → TikZ 그림**을 눌러 `.tikz` 파일로 저장합니다. 수정한 그림을 원본 시험지에 넣으려면 이 파일을 복원 대화에 첨부하고 해당 그림을 교체해 달라고 요청하세요.

## 할 수 있는 일

- 선분·화살표·원·호·부채꼴·사각형·다각형과 이름표를 그립니다.
- 격자, 좌표축, 기존 점·끝점·중점에 맞춰 그립니다. 연결된 점을 움직이면 선과 도형도 함께 따라갑니다.
- 함수·매개변수·극좌표 그래프를 식으로 그리고 매개변수를 움직입니다.
- 원의 둘레 두 곳을 찍어 호로 나누고, 원 부분을 지우거나 부채꼴을 만듭니다.
- 실행 취소·다시 실행, 여러 객체 선택, 복제, 레이어 순서, 색·선·채우기, 위치와 크기 조절을 사용합니다.
- 작업을 브라우저에 자동 저장하고 편집용 JSON, TikZ/TeX, SVG/PNG로 내보냅니다.

## 파일과 개인정보

그림은 사용자의 브라우저 안에서 처리됩니다. 로그인, 서버 저장, 그림 업로드, AI 호출 기능은 없습니다. 자동 저장은 현재 브라우저에만 남고, 편집한 그림을 다른 사람에게 보내려면 사용자가 파일을 직접 내려받아 전달해야 합니다. 브라우저의 사이트 데이터를 지우기 전에 보관하려는 도면을 JSON으로 저장하세요.

웹 편집기는 시험지 복원 에이전트와 연결되어 있지 않습니다. 에이전트가 편집기 사이트를 열거나 대신 조작하지 않습니다. 사용자가 직접 편집기를 열고 완료한 파일을 복원 대화로 가져오는 방식입니다. 웹 주소 자체는 공개되어 있으므로 인터넷을 사용하는 누구나 페이지를 열 수 있습니다. 그림 내용을 제3자에게 전송하는 기능은 앱에 두지 않았습니다.

## 지원 파일과 범위

열기: 이 앱의 JSON 프로젝트, TikZ 그림(`.tikz`), standalone LaTeX 문서(`.tex`). TikZ·TeX는 일부 자주 쓰는 문법을 도형으로 바꿔 편집합니다. 미지원 명령을 실행하거나 임의 TeX를 컴파일하지 않습니다. 인식하지 못한 원문은 보존되며 경고가 표시될 수 있습니다. 이 경우 해당 부분의 편집은 제한됩니다.

저장된 TikZ는 다른 수학 문서에 넣을 수 있습니다. 화면은 빠른 미리보기입니다. `.tex` 파일은 컴파일된 PDF가 아니므로 LaTeX 문서로 출력하려면 별도 TeX 환경이 필요합니다.

직접 설치하려면 Windows에 Node.js 22 이상을 준비하고 이 저장소 폴더에서 `npm ci`와 `npm run dev`를 실행합니다. 브라우저에서 표시된 로컬 주소를 엽니다.

## 설치 후 시험지 스킬에 연결하기

시험지 복원 스킬 사용자 안내에는 이 편집기 링크가 제공됩니다. 에이전트는 웹 편집기를 조작하지 않고, 사용자가 직접 저장해 다시 전달한 그림 파일만 요청에 따라 시험지에 반영합니다.

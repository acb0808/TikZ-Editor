# TikZ Editor

마우스와 속성 패널로 수학 도형을 그리고 TikZ 코드를 얻는 브라우저 기반 편집기입니다. 문서의 원본은 **JSON Scene Model**이며 SVG 화면, TikZ 코드와 내보내기는 이 모델을 사용합니다.

[**웹에서 TikZ Editor 열기**](https://acb0808.github.io/TikZ-Editor/)

도형과 수식은 브라우저에서 처리하며 서버에 그림을 저장하거나 AI에 보내지 않습니다. 에이전트는 이 웹 편집기를 열거나 조작하지 않습니다. 사용자가 직접 파일을 내려받아 필요한 곳에 다시 전달합니다.

## 시험지 도형을 직접 수정하기

1. 위 웹 편집기를 열고 폴더 모양 버튼으로 `.tikz`, `.tex` 또는 JSON 파일을 불러옵니다.
2. 캔버스에서 도형을 선택해 옮기거나, 속성 패널에서 위치·크기·색·라벨을 조정합니다.
3. 점·선·함수 그래프·영역 색칠·도형 자르기·수선을 사용해 그림을 고칩니다.
4. **내보내기 → TikZ 그림**으로 저장합니다. 편집을 이어갈 때는 JSON으로 저장하세요.
5. 수정한 그림을 다른 문서에 넣으려면 내려받은 `.tikz` 파일을 직접 전달하면 됩니다.

## 자체 동적 수학 및 기하 도구 (v0.3)

외부 GeoGebra를 불러오지 않습니다. 자체 계산·기하 모델로 다음 기능을 제공합니다.

- **함수 그래프(F)**: `y=x^2`, `a*sin(x)+b`, `1/x`, `sqrt(x)` 등의 수식 입력과 예제. 매개변수 `x(t), y(t)` 및 극좌표 `r(t)`도 지원합니다.
- **계수 슬라이더**: 속성의 a, b, c를 바꾸면 그래프와 그 위의 점이 함께 바뀝니다. 그래프를 드래그하면 식을 유지한 채 평행이동합니다.
- **표시 범위**: 함수의 x 또는 매개변수 t 범위를 설정합니다. 세로 표시 범위는 기본 -10~10이며 이미지와 TikZ에도 같은 범위를 사용합니다. 범위는 평행이동 전 좌표 기준입니다.
- **도형 위의 점(P)**: 선분·다각형 변·원·호·그래프 가까이 클릭하면 점을 연결합니다. 도형을 옮기면 따라가며 점만 끌면 도형을 따라 움직입니다. 속성에서 **연결 해제**할 수 있습니다.
- **교점 스냅**: 선분·사각형·다각형·원·호·그래프의 보이는 교점에 맞춥니다. 스냅된 교점은 현재 고정된 위치로 저장됩니다.
- **도형 자르기(X)**: 선분·화살표·사각형·다각형·원·호·부채꼴·수식 그래프를 선택하고, 자를 선을 가로지르는 두 점을 지정합니다. 닫힌 도형은 영역 조각으로, 열린 도형은 경로 조각으로 나뉘며 조각마다 이동·삭제할 수 있습니다. 원·부채꼴·호·그래프는 자르는 순간 근사 경로로 바뀝니다.
- **영역 색칠(B)**: 원·다각형·사각형·부채꼴 안쪽을 클릭하거나 선·도형·그래프가 둘러싼 닫힌 영역을 클릭해 색칠합니다. 색칠한 새 영역은 속성 패널에서 색과 투명도를 바꿀 수 있습니다.
- **수선(N)**: 점을 클릭한 뒤 기준 선분을 클릭해 수선을 내립니다. 수선의 발은 기준 선분에 연결되어 함께 움직입니다.
- **호·부채꼴 조절**: 중심·반지름·시작 각도·중심각을 입력하거나 끝점 핸들을 움직입니다. 그래프의 삼각함수는 라디안, 호·부채꼴 속성은 도(°) 단위를 사용합니다.

연결점은 기준 도형 삭제 시 현재 위치의 자유점으로 남습니다. 자른 도형 위의 연결점은 잘린 조각 중 가까운 경로에 다시 연결합니다. 자르기 후 원·호·부채꼴·그래프는 다각형이나 선분의 모음으로 바뀌어 원래 수식·곡선 매개변수는 유지되지 않습니다. 전체 GeoGebra 기능의 복제는 아직 완료된 상태가 아니며, CAS·3D·통계·고급 작도는 다음 확장 범위입니다.

**동적 관계는 JSON으로 보관하세요.** TikZ는 현재 계산된 그림을 내보냅니다. TikZ 코드를 다시 적용하면 경로에 연결된 점이 자유점으로 바뀝니다. 앱에서 내보낸 그래프는 검증된 주석 정보가 유지될 때 식으로 다시 편집할 수 있습니다. 외부에서 주석이나 곡선 좌표를 바꾸면 일반 경로로 처리할 수 있습니다.

### 닫힌 도형을 잘라 조각 지우기

1. 도형을 선택하고 왼쪽 **도형 자르기**를 누릅니다.
2. 도형을 가로지르도록 절단선 위의 두 점을 차례로 클릭합니다.
3. 생성된 조각을 선택해 옮기거나 삭제합니다. 모든 단계는 실행 취소할 수 있습니다.

## 실행

Node.js 22.12 이상 권장. 이번 작업에서는 Node.js 24에서 확인했습니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 로컬 주소(기본 `http://127.0.0.1:5173`)를 엽니다. `npm run build`로 정적 배포 파일을 만들고 `npm run preview`로 확인할 수 있습니다. 별도 서버, API 키 또는 사용자 계정이 필요하지 않습니다.

빌드 스크립트는 프로젝트의 `dist/`만 정리합니다. Windows의 동기화 폴더와 Node.js 24.13 조합에서 재귀 삭제 중 프로세스가 종료되는 현상을 피하기 위해 파일을 개별 삭제하며, 외부 경로로 연결된 폴더는 정리하지 않습니다.

## 구현한 기능

- 점, 선분, 화살표, 사각형, 원, 다각형, 일반 텍스트, 수식.
- 클릭/Shift 선택, 영역 선택, 드래그 이동, 꼭짓점·중심·반지름 핸들.
- 점을 참조하는 연결선: 참조 점을 이동하면 연결 객체도 이동합니다. 연결 객체 자체를 옮기면 선택 밖의 점과 연결을 해제합니다.
- 격자·점·끝점·중점 스냅과 가이드, 화면 이동, 포인터 기준 확대, 화면 맞춤.
- 좌표, 반지름, 색상, 굵기, 선 모양, 채우기, 불투명도, 화살촉, 수식·글자 크기 조절.
- 레이어 선택·이름·순서·숨김·잠금. Shift로 여러 객체 선택.
- 변경분 history, 한 번의 드래그를 한 번의 undo로 처리, redo, 복제, 앱 내부 copy/paste.
- Monaco 구문 강조·줄 번호·코드 편집·정리·복사. 코드 변경 후 **도면에 적용**으로 한 작업 단위로 동기화합니다.
- JSON 저장/불러오기, 브라우저 자동 저장. 잘못된 자동 저장 데이터는 덮어쓰지 않고 보존합니다.
- TikZ, standalone `.tex`, SVG, PNG 내보내기. SVG/PNG 수식은 MathJax의 벡터 경로로 변환하여 외부 폰트/HTML 없이 저장합니다.
- 한국어 UI와 작은 화면용 속성 패널.

저장 파일은 `version`, `scene`, `viewport`를 포함합니다. JSON을 읽을 때 버전·종류·참조·색상·숫자 범위를 검사합니다. 유효하지 않은 파일은 현재 도면에 적용하지 않습니다. 프로젝트 열기도 실행 취소가 가능합니다.

## 사용법

1. 왼쪽에서 도구를 선택합니다. 선·원·사각형은 드래그하고, 점·텍스트는 클릭합니다.
2. 다각형은 꼭짓점을 차례로 클릭한 후 첫 점을 다시 클릭하거나 Enter로 완성합니다. Esc로 취소합니다.
3. 선택 도구에서 도형을 드래그하거나 핸들로 크기를 바꿉니다. 오른쪽 속성 패널에서 정확한 값을 입력합니다.
4. TikZ 코드는 자동 갱신됩니다. 직접 코드를 수정할 때는 그림 편집이 잠시 비활성화되며, 적용하거나 취소하면 계속 편집할 수 있습니다.
5. 저장 아이콘은 다시 편집할 수 있는 JSON, 내보내기는 TikZ/이미지 파일을 만듭니다.

|단축키|동작|
|---|---|
|V / H|선택 / 화면 이동|
|P / L / A / R / C / G|점 / 선분 / 화살표 / 사각형 / 원 / 다각형|
|T / M|텍스트 / 수식|
|F / X / B / N|함수 그래프 / 도형 자르기 / 영역 색칠 / 수선|
|Space + 드래그 / 휠|화면 이동 / 확대·축소|
|Ctrl/Cmd + Z / Shift + Z|실행 취소 / 다시 실행|
|Ctrl/Cmd + C / V / D / A|객체 복사 / 붙여넣기 / 복제 / 전체 선택|
|Delete / Backspace|선택 객체 삭제|
|Ctrl/Cmd + S|프로젝트 파일 저장|

입력란과 코드 편집기에는 문서 단축키가 간섭하지 않습니다. 포인터를 누른 채 이동하는 동안 문서 삭제/undo 명령은 무시하고, Esc로 드래그를 취소할 수 있습니다.

## TikZ 지원 범위와 보존 규칙

자세한 문법은 [지원 문법 문서](docs/tikz-subset.md)를 참고하세요. 숫자 좌표, 이름 있는 좌표 참조, 기본 도형, 제한된 스타일, 일반/수식 node를 지원합니다. 전체 TeX 매크로 처리기는 아닙니다.

- 원본 명령·공백·주석을 순서 있는 `source` 항목에 보관합니다. 수정하지 않은 지원 명령과 미지원 영역은 원문을 보존합니다.
- 알 수 없는 옵션, scope, 매크로는 추측해서 도형으로 만들지 않습니다. 기존 지원 도형은 편집할 수 있습니다.
- 미지원 영역이 있으면 새로운 도형이 알 수 없는 설정을 상속할 수 있으므로 GUI의 **새 도형 생성·복제·붙여넣기·레이어 순서 변경**을 제한합니다. 새 도면으로 시작하거나 코드에서 해당 구문을 해결하면 정상 사용 가능합니다.
- 미지원 구문이 참조하는 좌표 선언을 손상시키지 않도록 이 경우 점 삭제도 제한합니다. 지원되는 도형의 위치·스타일 편집과 다른 도형의 삭제는 가능합니다.
- 미지원 코드가 있는 문서의 SVG/PNG에는 지원 도형만 포함됩니다. 원문 전체는 JSON 및 TikZ/TeX에 보존됩니다.
- 여러 그림이 있는 TeX 문서는 첫 번째 그림만 GUI에 투영합니다. 나머지 원문은 보존합니다.
- 격자와 좌표축은 현재 **편집 보조선**으로, 이미지 및 TikZ에 포함되지 않습니다.

## 현재 한계

- 화면은 빠른 SVG 미리보기입니다. KaTeX와 실제 TeX 사이에는 글꼴·자간·선 모양 차이가 있을 수 있습니다.
- 실제 LaTeX 컴파일, PDF 내보내기, 무한 직선/반직선, 일반 회전·대칭 변환, 베지어 곡선, 음함수·부등식 그래프, 동적 교점·수직이등분선·평행 등 고급 작도, CAS, 3D, 통계, 그룹, 클라우드 저장은 후속 범위입니다. 도형 자르기는 선분·화살표·사각형·다각형·원·호·부채꼴·그래프를 지원하며, 곡선은 자를 때 다각형/경로 조각으로 근사됩니다.
- 생성된 `.tex`의 기본 도형 변환과 round trip을 테스트했습니다. 이 작업 환경의 내장 TeX 컴파일러가 `Unable to find standard directories for platform` 오류를 반환하여 실제 컴파일 성공은 확인하지 못했습니다.
- UI 글꼴은 선택적으로 Google Fonts를 사용하며, 연결이 없으면 시스템 글꼴로 대체됩니다. Monaco와 수식 렌더러는 로컬 번들입니다.
- 정밀 편집은 데스크톱 마우스/키보드를 우선합니다. 모바일은 도구와 속성 패널을 사용할 수 있지만 작은 작업 영역의 제약이 있습니다.
- MathJax·Monaco는 필요한 시점에 로딩하는 큰 번들입니다. 대규모 프로젝트 성능 최적화와 worker 기반 파싱은 후속 작업입니다.

## 구조 및 설계

```
src/core/        Scene schema, 좌표, 기하, 스냅, history, JSON 검증
src/state/       Zustand 상태와 transaction 경계
src/tools/       도구 registry와 도형 생성
src/canvas/      SVG 렌더러와 포인터 조작
src/components/ 속성·레이어·도구·Monaco 패널
src/tikz/        부분 parser와 generator
src/io/          저장과 벡터/이미지 export
tests/browser/   실제 브라우저 회귀 검사
```

[조사·아키텍처 설계](docs/plans/2026-09-27-tikz-studio-design.md)와 [단계별 구현 계획](docs/plans/2026-09-27-tikz-studio.md)에 오픈소스 비교, 라이선스, 렌더러 선택, Scene schema, 좌표 변환, history, snapping 확장 방향을 기록했습니다. 외부 편집기 코드를 복사하지 않고 독립 구현했습니다.

## 검증

```sh
npm test
npm run build
npm run test:e2e
npm audit
```

브라우저 검사는 설치된 Google Chrome을 기본으로 사용합니다. 다른 환경에서는 `playwright.config.ts`의 `channel`을 제거하고 `npx playwright install chromium`을 실행하면 됩니다. 테스트는 새 브라우저 컨텍스트에서 실행되며 실제 사용자 프로젝트를 수정하지 않습니다. 캡처와 테스트 내보내기 결과는 `test-results/`에 생성됩니다.

도형·좌표·스냅·변환·history·프로젝트 검증을 순수 함수 테스트로 확인하고, 브라우저에서는 드래그·연결점·핸들·JSON 재열기·TikZ 적용·실제 이미지 다운로드·작은 화면을 검증합니다.

v0.2에서는 단위 검사 **209개**, 실제 브라우저 검사 **16개**가 통과했습니다. v0.3의 도형 자르기·영역 색칠·교점 스냅·수선 추가분은 타입 검사와 프로덕션 빌드를 통과했습니다.

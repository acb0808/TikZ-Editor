# 자체 동적 수학 편집 확장

사용자는 외부 GeoGebra를 넣지 않고 자체 기능을 단계적으로 확장하는 방식을 선택했다. 기존 JSON Scene → SVG/TikZ 구조를 유지한다.

## 선택과 범위

전체 GeoGebra를 내장하는 방식은 폭넓은 기능을 즉시 얻지만 사용자 선택과 맞지 않고 TikZ 원본 모델도 공유할 수 없다. 화면에 샘플 곡선만 추가하는 방식은 구현이 짧지만 점의 연결 관계가 사라진다. 따라서 수식과 경로 제약을 Scene에 저장하고, 렌더링 시 실제 위치를 계산하는 자체 방식을 사용한다.

이번 단계: y=f(x), 매개변수 곡선, 극좌표 곡선, a/b/c 계수 슬라이더; 선·원·호·그래프 위의 점과 교점 스냅; 원 둘레 두 위치로 두 호를 만든 뒤 선택한 호 삭제 또는 부채꼴 변환. 이동·핸들·실행 취소·JSON 재열기·TikZ/이미지 출력까지 통합한다. CAS, 3D, 통계, 전체 고급 작도는 후속 단계이다.

## 모델과 동작

- point.binding = {objectId,t,segment?}. t는 [0,1], 다각형의 segment는 변 번호이다. 경로를 옮겨도 점의 제약은 유지하고, 점을 드래그하면 경로에 투영한다. 연결 해제는 명시적 동작이다.
- arc/sector = center, radius, startAngle, sweepAngle. 각도는 도 단위이며 중심각은 반시계방향이 양수, 시계방향이 음수이다. 원 나누기는 하나의 history 작업이며 기존 연결점을 해당 호에 재연결한다.
- plot = mode, expression, xExpression, xMin, xMax, parameters. 입력식은 허용된 연산자·함수만 해석하며 JavaScript를 실행하지 않는다. 삼각함수 입력은 라디안이다. 불연속 구간은 연결하지 않는다.
- 참조 순환·존재하지 않는 경로·잘못된 식·과도한 범위를 JSON 검증에서 거부한다. 호스트 삭제 시 종속 점은 현재 좌표에서 자유점이 된다.
- TikZ는 정적인 결과 그림이다. 동적 관계를 정확히 보관하는 원본은 JSON이며, 식·동적 정보의 TikZ 왕복은 지원 가능한 메타데이터와 파싱 범위를 명시한다.

## 구현과 검증

Core(형상·스냅·검증), 수식/TikZ 변환, Canvas/renderer, UI를 나누어 구현한다. 계산·투영·경로 삭제/복제·참조 순환·불연속 그래프를 단위 검증하고, 실제 브라우저에서 그래프 입력→계수 변경→점 부착→호스트 이동→원 분할→부채꼴→저장/복원을 확인한다. 기존 편집 기능의 회귀 검사도 유지한다.
